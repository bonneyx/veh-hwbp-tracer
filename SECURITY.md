# Security Policy

## Security Maintainer

- **Lead Security Maintainer:** [@bonneyx](https://github.com/bonneyx)
- **Scope:** Vectored Exception Handler (`veh_tracer.hpp`) context sanitization and hardware debug register (`DR0`-`DR7`) state isolation.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report any exception-chain hijacking or register context corruption issues privately via [GitHub Security Advisories](https://github.com/bonneyx/veh-hwbp-tracer/security/advisories/new).
